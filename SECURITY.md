# Security Policy

## Reporting a Security Vulnerability

If you discover a security vulnerability in PrinceHacky, please report it privately instead of creating a public GitHub issue.

Please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The affected page, feature, or file
* Any relevant screenshots or error messages
* Information about the potential impact

Please do not publicly disclose the vulnerability until it has been investigated and resolved.

## What to Report

Examples include:

* Exposed API keys or secrets
* Authentication or authorization problems
* Database security issues
* Cross-site scripting vulnerabilities
* Unexpected access to private data
* Other security issues that could affect users or the website

## Response

We will review valid security reports and work to understand and fix confirmed vulnerabilities.

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

## Out of Scope

The following are generally not considered security vulnerabilities:

* Spelling or grammar mistakes
* Normal website bugs without a security impact
* Feature requests
* Issues caused by unsupported browsers or devices
* Automated scanning reports without evidence of an exploitable vulnerability

Thank you for helping keep PrinceHacky secure.
